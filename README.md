# ระบบลงรับและติดตามเอกสาร (ไปราชการ/โครงการ)

หน้าเว็บอยู่บน **GitHub Pages** ส่วนข้อมูลและการล็อกอินอยู่บน **Google Apps Script + Google Sheet**
(GitHub Pages เป็นที่เก็บเว็บแบบคงที่ ไม่มีฐานข้อมูล จึงต้องมีส่วน Apps Script เป็นฝั่งเซิร์ฟเวอร์)

```
เบราว์เซอร์ ──► GitHub Pages (index.html, config.js)
                    │  fetch (POST)
                    ▼
              Apps Script Web App (apps-script/Code.gs) ──► Google Sheet ของคุณ
```

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งระบบ (ไฟล์เดียว) |
| `config.js` | ใส่ลิงก์ Apps Script (`API_URL`) |
| `apps-script/Code.gs` | โค้ดฝั่งเซิร์ฟเวอร์ ที่ต้องนำไปวางใน Apps Script |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตามที่เป็น |

> **ถ้าไม่ใช้ GitHub** ให้ใช้โหมด Apps Script ล้วนแทน: วางไฟล์ `Code.gs` และ `Index.html` จากโฟลเดอร์ `apps-script-v2` ในโปรเจกต์ Apps Script เดียว (ไฟล์ HTML ต้องตั้งชื่อ `Index`) แล้ว Deploy เป็น Web app

---

## ขั้นที่ 1 — ตั้งค่าฝั่งเซิร์ฟเวอร์ (Apps Script)
1. สร้าง Google Sheet ใหม่ (หรือใช้ชีต "Data" เดิม) → เมนู **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิม แล้ววางโค้ดจาก `apps-script/Code.gs` (โหมดนี้ **ไม่ต้องสร้างไฟล์ Index.html**)
3. เลือกฟังก์ชัน **`setup`** กด **Run** ครั้งแรก → อนุญาตสิทธิ์เข้าถึงชีต (ถ้าขึ้นคำเตือน กด ขั้นสูง → ไปที่โปรเจกต์)
4. กด **Deploy > New deployment** → ประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (จำเป็น ถ้าเลือกเฉพาะคนในองค์กร หน้าเว็บบน GitHub จะเรียกไม่ได้)
5. คัดลอกลิงก์ที่ลงท้ายด้วย **`/exec`**
6. ทดสอบ: เปิดลิงก์นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `{"ok":true,"service":"travel-docs-api"}`

## ขั้นที่ 2 — ใส่ลิงก์ในหน้าเว็บ
แก้ไฟล์ `config.js` ให้เป็นลิงก์ที่ได้จากขั้นที่ 1:
```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfycb.../exec'
};
```

## ขั้นที่ 3 — ทดสอบในเครื่อง (ไม่บังคับ แต่แนะนำ)
เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน
```bash
python3 -m http.server 8000      # Windows: python -m http.server 8000
```
เปิด http://localhost:8000 → ทดสอบล็อกอิน `admin` / `1234` แล้ว**เปลี่ยนรหัสผ่านทันที**

## ขั้นที่ 4 — นำขึ้น GitHub
**วิธี A: ผ่านหน้าเว็บ GitHub (ง่ายที่สุด ไม่ต้องติดตั้งอะไร)**
1. สมัคร/เข้าสู่ระบบ github.com → **New repository** ตั้งชื่อเช่น `travel-docs` (เลือก **Public**) → Create
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป (รวมโฟลเดอร์ `apps-script` และไฟล์ `.nojekyll`) → **Commit changes**

**วิธี B: ใช้ Git**
```bash
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/travel-docs.git
git push -u origin main
```

## ขั้นที่ 5 — เปิด GitHub Pages
1. ใน repository ไปที่ **Settings > Pages**
2. Source เลือก **Deploy from a branch** → Branch: **main** / โฟลเดอร์ **/ (root)** → **Save**
3. รอ 1–3 นาที ลิงก์ใช้งานจะเป็น `https://<ชื่อผู้ใช้>.github.io/travel-docs/`

## การอัปเดตภายหลัง
- **แก้หน้าเว็บ** (`index.html`, `config.js`): แก้ไฟล์แล้ว commit/push รอ Pages อัปเดตสักครู่
- **แก้ฝั่งเซิร์ฟเวอร์** (`Code.gs`): วางโค้ดใหม่ใน Apps Script แล้ว **Deploy > Manage deployments > แก้ไข > Version: New version > Deploy** ลิงก์ `/exec` เดิมไม่เปลี่ยน (ถ้าลืมทำขั้นนี้ โค้ดเก่ายังทำงานอยู่)

## ระบบหลังบ้าน (เฉพาะ admin)
ล็อกอินด้วย `admin` แล้วไปที่ **👤 เจ้าหน้าที่ > ⚙️ หลังบ้าน** (แท็บนี้มองเห็นเฉพาะ admin)
| ส่วน | ใช้ทำอะไร |
|---|---|
| 🏥 ตั้งค่าหน่วยงานและหัวเว็บ | เปลี่ยนชื่อโรงพยาบาล ชื่อระบบ ข้อความใต้ชื่อระบบ และอัปโหลดโลโก้ (ระบบย่อรูปให้อัตโนมัติ) |
| 📋 ตัวเลือกในฟอร์ม | แก้รายการสังกัดกลุ่มงาน ประเภท/กิจกรรม แหล่งงบประมาณ หมวดหมู่ และเหตุผลการยกเลิก (พิมพ์หนึ่งตัวเลือกต่อบรรทัด) ประเภท/กิจกรรมต้องมี "จัดโครงการ" เสมอ เพราะระบบใช้ตัวเลือกนี้เปิดตารางงบแบบรายการ |
| 👥 ผู้ใช้เจ้าหน้าที่ | เพิ่มผู้ใช้ รีเซ็ตรหัสผ่าน ลบผู้ใช้ ผู้ใช้ใหม่ต้องเปลี่ยนรหัสผ่านเมื่อเข้าครั้งแรก และทุกคนเปลี่ยนรหัสผ่านของตัวเองได้จากแถบด้านบน |
| 💾 ข้อมูลและการสำรอง | ดาวน์โหลดไฟล์สำรองข้อมูลทั้งหมด (.json ไม่รวมรหัสผ่าน) และลบถาวรรายการที่ยกเลิกแล้ว (ต้องพิมพ์ยืนยัน) |

การตั้งค่าเหล่านี้เก็บในชีตของคุณ (ชีตซ่อน `_docs`) จึงไม่หายเมื่ออัปเดตหน้าเว็บ ชื่อโรงพยาบาลเริ่มต้นเป็น "โรงพยาบาลตาพระยา" แก้ได้ที่หลังบ้าน

## ข้อควรรู้ด้านความปลอดภัย
- Repository แบบ Public มองเห็นโค้ดหน้าเว็บและลิงก์ `API_URL` ได้ ซึ่งเป็นเรื่องปกติของเว็บแบบนี้ **ห้ามใส่รหัสผ่านหรือข้อมูลจริงลงใน repository**
- ข้อมูลทั้งหมดอยู่ในชีตของคุณ ไม่อยู่ใน GitHub
- ข้อมูลฝั่งเจ้าหน้าที่ (งบ ยืม/เบิก อีเมล เอกสาร) ต้องล็อกอินก่อนจึงจะอ่านได้ ตรวจที่เซิร์ฟเวอร์ แต่หน้าติดตามสถานะ (ชื่อ ชื่อเรื่อง กลุ่มงาน สถานะ เลขยืมเงิน) ใครมีลิงก์เว็บก็ดูได้
- ผู้ใช้เริ่มต้น `admin` / `1234` เปลี่ยนรหัสผ่านทันทีหลังเข้าครั้งแรก ใส่ผิด 5 ครั้งจะถูกล็อก 5 นาที (ผู้ดูแลรีเซ็ตให้ได้) เข้าสู่ระบบอยู่ได้ 6 ชั่วโมง
- สิทธิ์แยก 2 ระดับ: admin (หลังบ้านทั้งหมด) และเจ้าหน้าที่ (ลงรับ ยืม/เบิก คืนเงิน รายงาน) ตรวจที่เซิร์ฟเวอร์
- ถ้าต้องการ repository แบบ Private ต้องมีแพ็กเกจ GitHub ที่รองรับ Pages แบบ Private (ฟรีใช้ได้เฉพาะ Public)

## แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|---|---|
| ขึ้น "Cannot read properties of null (reading 'getSheetByName')" | สคริปต์ไม่ได้ผูกกับชีต ให้ใส่ ID ของ Google Sheet ที่ `const SHEET_ID = '...'` บรรทัดบนของ `Code.gs` (ID อยู่ในลิงก์ชีตระหว่าง `/d/` กับ `/edit`) แล้วรัน `setup` อีกครั้ง และ Deploy เป็น New version |
| ขึ้น "ยังไม่ได้ตั้งค่า API_URL" | แก้ `config.js` ให้เป็นลิงก์ `/exec` ของคุณ แล้ว push |
| ขึ้น "Failed to fetch" / "เซิร์ฟเวอร์ตอบกลับไม่ถูกต้อง" | ตรวจว่า Who has access = **Anyone**, ใช้ลิงก์ที่ลงท้าย **/exec** (ไม่ใช่ /dev) และได้ Deploy เวอร์ชันใหม่หลังแก้โค้ด |
| ล็อกอินไม่ได้ทั้งที่รหัสถูก | รัน `setup` ใน Apps Script อีกครั้ง แล้วลองใหม่ ถ้าเคยใส่ผิดหลายครั้ง ให้รอ 5 นาที |
| หน้า GitHub Pages ขึ้น 404 | รอ 3 นาที ตรวจ Settings > Pages ว่าเลือก branch main / root และไฟล์ `index.html` อยู่ที่ราก repository |
| ปุ่มส่งออกไม่ดาวน์โหลด | ตรวจว่าเบราว์เซอร์ไม่บล็อกการดาวน์โหลดจากเว็บไซต์นี้ |
| ข้อมูลไม่อัปเดตในชีต "รายการ" | ชีตนี้เป็นสำเนาอ่านอย่างเดียว แก้ในชีตแล้วไม่ย้อนกลับเข้าระบบ ข้อมูลหลักอยู่ในชีตซ่อน `_docs` (ห้ามแก้ด้วยมือ) |

## ข้อจำกัด
- เรียกผ่านเซิร์ฟเวอร์ของ Google จึงมีหน่วงประมาณ 1–3 วินาทีต่อการบันทึก และมีโควตาการเรียกต่อวันของ Apps Script (เพียงพอสำหรับหน่วยงานขนาดเล็ก–กลาง)
- การแจ้งเตือนครบกำหนดคืนเงินแสดงบนหน้าจอตอนเปิดหน้าเว็บ ไม่ส่งอีเมลอัตโนมัติ ปุ่ม "แจ้งอีเมล" เปิดโปรแกรมอีเมลของผู้ใช้พร้อมข้อความที่เตรียมไว้
- วันทำการนับเฉพาะจันทร์–ศุกร์ ยังไม่หักวันหยุดนักขัตฤกษ์


## แท็บ "ทำบันทึกข้อความ" (เปิดให้ทุกคน)

- ไม่ต้องล็อกอิน เมื่อกด "บันทึกข้อมูลเข้าระบบ" หรือพิมพ์เอกสาร ข้อมูลจะถูกเก็บในชีต **"บันทึกข้อความ"** (และ _docs path memos/…) เพื่อเรียกกลับมาใช้ซ้ำ/ใช้ทำบันทึกข้อความแบบอื่นต่อได้
- รายการที่บันทึกไว้ทุกคนที่เข้าเว็บเห็นและเรียกใช้เป็นต้นแบบได้ แก้ทับได้เฉพาะเครื่องที่เป็นผู้บันทึก ลบได้เฉพาะเจ้าหน้าที่ที่ล็อกอิน
- ต้องวาง Code.gs ชุดล่าสุดและ Deploy เวอร์ชันใหม่ จึงจะบันทึกได้
- ตอนนี้มี 1 แบบ: **ขออนุมัติจัด** (เลือกจากรายการ "ประเภทบันทึกข้อความ") ถ้าจะเพิ่มแบบอื่น แจ้งตัวอย่างไฟล์มาได้
- ผลลัพธ์: พิมพ์/บันทึกเป็น PDF (กดปุ่มแล้วเลือก "Save as PDF") หรือดาวน์โหลดเป็นไฟล์ .doc เปิดแก้ใน Word ได้
- ตราครุฑ: อัปโหลดรูปครุฑของหน่วยงานในแบบฟอร์ม (จำไว้ในเครื่อง); ชื่อ/ตำแหน่งผู้ลงนามจำได้เฉพาะเครื่องนั้น
- รายชื่อกลุ่มงานที่ให้เลือกดึงจากหลังบ้าน (ตั้งค่า > สังกัดกลุ่มงาน)

### ประเภทบันทึกข้อความ (อัปเดตล่าสุด)

เลือกจากรายการ "ประเภทบันทึกข้อความ": ขออนุมัติจัด · ขออนุมัติดำเนินการ (จ้างเหมา/เช่า ก่อนจัด) · ขออนุมัติยืมเงิน · ขออนุมัติเบิกจ่ายเงิน (หลังจัด) · ขออนุมัติคืนเงินยืม

- เลือก **กลุ่มงาน** (11 กลุ่ม) ระบบใส่เลขที่หนังสือ `สก 0033.301.03.<รหัสกลุ่ม>/` ให้ ผู้ใช้กรอกแค่เลขลำดับ ถ้าพิมพ์หลายฉบับพร้อมกัน เลขจะรันต่อเนื่อง (2628, 2629, ...)
- ประเภทดำเนินการ/ยืมเงิน/เบิกจ่าย/คืนเงิน: บันทึก "ขออนุมัติจัด" ไว้ก่อน แล้วเลือกรายการนั้นในช่อง "ข้อมูลที่บันทึกไว้" กด **ใช้เป็นกิจกรรมต้นทาง** ระบบดึงชื่อกิจกรรม วันที่ สถานที่ จำนวนคน งบ และเลขที่/วันที่หนังสืออนุมัติมาใส่ แก้ได้ทุกช่อง
- รายการค่าใช้จ่าย 6 แบบ (อาหารกลางวัน, อาหารว่างและเครื่องดื่ม, อาหารไม่ครบมื้อ, เช่าที่พัก, เช่าห้องประชุม, ค่าสมนาคุณวิทยากร) คำนวณยอดและตัวหนังสือให้ ติ๊กหลายรายการได้ ระบบสร้างแยกฉบับ
- ต้องวาง `Code.gs` ชุดล่าสุดแล้ว Deploy เวอร์ชันใหม่ เพื่อให้บันทึกประเภทใหม่ได้

### หน้าตาแบบ TPY + เลือกสีธีม
- เมนูอยู่แถบซ้าย มีการ์ดต้อนรับด้านบน (มือถือ: เมนูเลื่อนแนวนอนด้านบน)
- ปุ่ม **🎨 สีธีม** มุมขวาบน: กดเลือกได้ 8 สี หรือกด "เลือกสีเอง" เพื่อเลือกสีใดก็ได้ — เปลี่ยนทั้งระบบทันที และจำค่าไว้ในเครื่องของแต่ละคน (คืนค่าเริ่มต้นได้)

### หน้าแรก (Dashboard) / ปฏิทิน / คลัง SOP
- **หน้าแรก:** การ์ดสรุปตามปีงบประมาณ, กราฟรับเรื่อง 7 วันย้อนหลัง, สัดส่วนตามสถานะ, รายการใกล้ครบ/เกินกำหนดคืนเงินยืม (เห็นเฉพาะเจ้าหน้าที่), ปฏิทินย่อ, เมนูลัด — ใช้ข้อมูลจริงจากฐานข้อมูล ถ้าเชื่อมต่อไม่ได้จะแสดงป้าย "ข้อมูลตัวอย่าง (Demo)" ชัดเจน
- **ปฏิทินกิจกรรม:** ดึงจากวันที่เดินทาง/จัดกิจกรรมของแต่ละรายการ กดวันเพื่อดูรายการ กดรายการเพื่อดูรายละเอียด
- **คลังเอกสาร SOP:** ทุกคนค้นหา/เปิดดูได้ เจ้าหน้าที่เพิ่มเอกสาร (เก็บเป็นลิงก์ https เช่น Google Drive) ผู้ดูแลระบบลบได้ — **ต้องอัปเดต Code.gs เป็นเวอร์ชันล่าสุดและ Deploy ใหม่** จึงจะใช้ได้
- **ช่องค้นหาด้านบน:** พิมพ์แล้วกด Enter ไปที่หน้าติดตามสถานะพร้อมกรอง | **กระดิ่ง:** แจ้งเตือนรายการใกล้ครบ/เกินกำหนด (เจ้าหน้าที่)
- **โลโก้และรูปอาคาร:** ตั้งค่าที่เมนู ตั้งค่าระบบ (อัปโหลดโลโก้จริง / ใส่ลิงก์รูปอาคาร) — ระหว่างนี้แสดงช่อง "LOGO" ไม่มีตราที่สร้างขึ้นเอง
- รายการเก่าที่เคยบันทึกก่อนอัปเดต ไม่มีวันที่ในข้อมูลสาธารณะ จึงเห็นบนปฏิทิน/กราฟเต็มรูปแบบเมื่อเข้าสู่ระบบเจ้าหน้าที่ (รายการใหม่จะมีครบ)

### สไตล์หน้าจอ "AI Future Tech"
ปุ่ม 🎨 สีธีม → "สไตล์หน้าจอ" เลือก **สว่าง (มาตรฐาน)**, **Tech สว่างใส** (พื้นขาว-ฟ้าอ่อน เมนูขาว ฟ้าเรืองแสง) หรือ **Tech มืด** (น้ำเงินเข้ม ดำอมกรมท่า ฟ้าเรืองแสง) — ยังเลือกสีหลักได้ จำค่าไว้ในเครื่องแต่ละคน ฟอร์มบันทึกข้อความและเอกสารพิมพ์ยังเป็นพื้นขาวตามเดิม

### วันไปราชการ/โครงการหลายช่วง (หลายรอบในเอกสารฉบับเดียว)
- ในหน้าลงทะเบียน (เจ้าหน้าที่) กด **➕ เพิ่มช่วงวันที่** ได้ไม่จำกัด จำนวนวัน = ผลรวมทุกช่วง
- ระบบตรวจว่าช่วงไม่ซ้อนทับกัน แสดงวันที่ทุกช่วงในรายการ/รายละเอียด/Excel (คอลัมน์ "ช่วงวันที่ (ทุกรอบ)") และขึ้นปฏิทินทุกช่วง
- "ตั้งแต่/ถึงวันที่" ในรายงานและตัวกรองเดือน ใช้ช่วงแรกสุด–ช่วงท้ายสุด; รายการเก่าที่มีช่วงเดียวใช้ได้ตามเดิม

## ปีงบประมาณและงบแผนรายกลุ่มงาน
- ปีงบประมาณของรายการ นับตามวันเดินทางวันแรก (1 ต.ค.–30 ก.ย.) ส่วนเลขรับ/เลขยืมเงินยังนับตามวันที่ลงรับ
- ผู้ดูแลระบบกรอกงบแผนที่ ตั้งค่าระบบ → "งบแผนไปราชการ/โครงการ รายกลุ่มงาน" (เก็บที่ meta/plan-<ปีงบ>)
- แดชบอร์ด (รายงานและสถิติ) แสดงงบแผน/ใช้ไป/คงเหลือ รายกลุ่มงาน สลับทั้งปี/รายเดือน และรวม/ไปราชการ/โครงการ
- **ต้องวาง Code.gs ใหม่ใน Apps Script แล้ว Deploy เวอร์ชันใหม่** (เพิ่มการจำกัดให้เฉพาะผู้ดูแลระบบบันทึกงบแผนได้)

## เลขยืมเงิน
พิมพ์เองในฟอร์มยืมเงิน รูปแบบ เลข/ปีงบประมาณ (เช่น 12/2570) ช่องเลขจะมีเลขสีเทาแสดงลำดับถัดไปของปีงบนั้น เว้นว่างเพื่อใช้เลขนั้น หรือพิมพ์ทับได้ ระบบกันเลขซ้ำ

## สิทธิ์การใช้งาน
- ทุกคนที่เปิดเว็บดูข้อมูลได้ทั้งหมด (รวมหน้ารายงาน) แบบอ่านอย่างเดียว (อีเมลผู้ขอเห็นเฉพาะผู้ที่ล็อกอิน)
- แก้ไขได้เฉพาะผู้ที่ล็อกอิน และตามสิทธิ์ที่ผู้ดูแลระบบติ๊กให้รายคน: ลงรับ/แก้ไข/ยกเลิกเอกสาร · ยืม/เบิกเงิน · คืนเงินยืม · จัดการคลัง SOP (ผู้ดูแลระบบมีทุกสิทธิ์)
- ตั้งชื่อที่แสดงและสิทธิ์ได้ที่ ผู้ดูแลระบบ → ผู้ใช้เจ้าหน้าที่ (ผู้ใช้เดิมที่ยังไม่เคยตั้งสิทธิ์ จะได้ 4 สิทธิ์แรกเหมือนเดิม)
- สิทธิ์ถูกตรวจที่ฝั่ง Apps Script ด้วย ต้องวาง Code.gs ใหม่แล้ว Deploy เวอร์ชันใหม่
